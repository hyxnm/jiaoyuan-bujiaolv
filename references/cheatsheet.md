# 决策规则速查 — 毛选方法论（四源去重蒸馏）

| 能力 | 一句话规则 |
|---|---|
| 调查研究法 | 说出不三个具体数字，你就还没资格决策 |
| 抓主要矛盾 | 别问哪个最急，问解决了它，别的会不会跟着松动 |
| 集中优势兵力 | 三倍于敌，打最软的一点，全歼速决再转下一个 |
| 持久战阶段法 | 只看经常起作用的因素在变好还是变坏，再决定坚持还是转向 |
| 群众路线闭环 | 收集→研究加工→形成主张→回到对象→在行动中检验→再收集 |
| 弹钢琴与抓紧 | 有节奏地统筹，抓而不紧等于不抓 |
| 反对党八股 | 提出问题→分析问题→指明性质→给解决办法；反的是空，不是长 |
| 认识加工十六字 | 去粗取精、去伪存真、由此及彼、由表及里，四道走完才下判断 |
| 胸中有数 | 到什么数字它就算成立——说出这个数字，才有讨论的起点 |
| 划清界限 | 先定性（什么性质），再定量（三分还是七分） |
| 矛盾性质判断 | 先判对抗性还是非对抗性，再选打法——判错是灾难 |
| 分层与分寸 | 按利益位置分四档——依靠/争取/中立/防范，重点投"争取"档 |
| 有理有利有节 | 有理（被侵犯才出手）有利（有把握才打）有节（得手就收） |
| 战略藐视战术重视 | 敢想 + 细打，两端缺一不可 |
| 决策前六问清单 | 重大决策前过六问，缺一项先补再定 |
| 突破一点再推广 | 试点是验证号召本身的工具，不只是试试看 |
| 放下包袱开动机器 | 先卸情绪负担，再用脑筋——把包袱写下来，力量减半 |
| 惩前毖后治病救人 | 对事不对人，落点是改进不是追责 |
| 实践—认识螺旋 | 每轮必须比上轮"高"一级，否则是原地打转 |
| 报告制度 | 频率/格式/责任人/反馈四要素，关键报告负责人亲写 |
| 反对本本主义 | 任何外部经验都要过一道本地化改造；关键路径不押外部资源 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
