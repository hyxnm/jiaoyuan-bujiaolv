# 弹钢琴与抓紧 — 有节奏地统筹，抓而不紧等于不抓

## R — 原文 (Reading)

> 「弹钢琴要十个指头都动作，不能有的动，有的不动。但是，十个指头同时都按下去，那也不成调子。要产生好的音乐，十个指头的动作要有节奏，要互相配合。党委要抓紧中心工作，又要围绕中心工作而同时开展其它方面的工作。……凡是有问题的地方都要点一下。」

> 「党委对主要工作不但一定要『抓』，而且一定要『抓紧』。……抓而不紧，等于不抓。伸着巴掌，当然什么也抓不住。就是把手握起来，但是不握紧，样子像抓，还是抓不住东西。」

> 「『互通情报』。就是说，党委各委员之间要把彼此知道的情况互相通知、互相交流。这对于取得共同的语言是很重要的。」

> 「开会要事先通知，像出安民告示一样，让大家知道要讨论什么问题，解决什么问题，并且早作准备。……如果没有准备，就不要急于开会。」

> 「不懂得和不了解的东西要问下级，不要轻易表示赞成或反对。……先做学生，然后再做先生。」

—— 毛泽东《党委会的工作方法》

## I — 方法论骨架 (Interpretation)

这一门管**日常怎么运转**，是最"能立刻用"的一门。核心是五条纪律：

1. **弹钢琴**：所有方面都要照顾到（不能有的动有的不动），但**有节奏、有主次**（不能同时按下去）。中心工作抓紧，其余围绕中心配合。
   - "凡是有问题的地方都要点一下" = **不遗漏**，不是**平均用力**
2. **抓紧**：抓而不紧，等于不抓。**"在做"和"做成"是两回事。**
   - 每个重要事项必须补齐三个字段：**谁负责 / 什么算做成（可验收产出）/ 什么时候交**
   - 三个常见松手点：布置了但没定验收标准 / 定了标准但没定时间 / 定了时间但没中途检查
3. **摆桌面**：有问题就开会摆出来，不背后议论、不拖。开会只谈事不谈人，谈完**当场定下几条**写下来
4. **先当学生**：不懂就问下级，先请教再下命令。这不丢威信，反而增加威信
5. **安民告示 + 互通情报**：会前通知议题+材料（没准备就不开会）；成员之间主动交流情况，不交流就"缺乏共同的语言"

**判据**：你的日历上，中心工作有没有拿到最大的连续时间块？如果没有，你就没在弹钢琴，你在乱弹。

## A1 — 书中的应用 (Past Application)

### 案例 1：《党委会的工作方法》十二条（1949-03）
- **问题**：即将执掌全国政权的干部，需要一份可操作的工作方法清单
- **方法论的使用**：十二条几乎全是操作细节——第一条"当班长"、第三条"互通情报"（批评"鸡犬之声相闻，老死不相往来"）、第六条"抓紧"、第八条"安民告示"（批评"兵马已到，粮草未备"）、第十一条"力戒骄傲"、第十二条"划清两种界限"
- **结论**：把这套方法直接当团队管理检查表
- **结果**：成为最有操作性的领导方法文献

### 案例 2：多业务线自媒体（商业源迁移例）
- **问题**：同时管内容创作、社群运营、产品交付、商务合作四条线
- **方法论的使用**：①确定本月中心任务（"上架新课，首周销量 100 份"）②每条线设不同跟进节奏（中心日跟、重要周跟、常规月跟）③建立信息通气机制（有团队每周 15 分钟站会，一人时每周日晚 30 分钟复盘）
- **结论**：中心工作占大块连续时间，其余占小块固定时间
- **结果**：不再顾此失彼

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 同时推多个方向，感觉顾此失彼
2. 团队各管各的，信息不通，出了问题才发现
3. 开了很多会但没有结果，议而不决、决而不行
4. 只顾着抓一件事，其他事没人管
5. 一件事"在做了"三个月，没有结果
6. 多头任务，天天救火，感觉很忙但事情没推进

### 语言信号

- "忙不过来 / 天天救火"
- "什么事都推不动"
- "多项目怎么统筹"
- "开会没结论，开完等于没开"
- "安排了但没人执行 / 执行了但没结果"
- "事情总落不了地"

### 与相邻能力的区分

- 与 `mao-focus-force`（集中优势兵力）的区别：集中兵力解决"**选一个点打透**"，本卡解决"**其余方向如何维持而不投入**"。两者配套：集中的是中心工作，本卡管"辅以"的第二第三位工作。
- 与路由入口内的"报告制度"的区别：报告制度是**信息流制度设计**（团队扩张后防失联），本卡是**日常运转的注意力分配与执行纪律**。报告制度是本卡"互通情报"在组织规模扩大后的延伸。
- 与路由入口内的"惩前毖后治病救人"的区别：本卡管**事**（推进落地），那个管**人**（团队纠偏）。

## E — 可执行步骤 (Execution)

1. **弹钢琴：排好节奏**
   - 列出当前所有"必须有动作"的方面（一个都不能漏）
   - 标出**中心工作**（只有一件）+ 其余按"第二位、第三位"排开，明确每项的**最低维持标准**（不是目标，是底线）
   - 排进日历：中心工作占大块连续时间，其余占小块固定时间
   - 完成标准：日历上中心工作拿到了最大的连续时间块

2. **抓紧：把"在做"变成"做成"**
   - 对每个重要事项补三个字段：谁负责 / 什么算做成（可验收产出）/ 什么时候交
   - 任何超过一周的事，中间至少检查一次
   - 完成标准：每件事都有"什么算做成"这一列（没有这列=没抓）
   - 判停条件：若反复检查仍无进展 → 查"方法/资源给了没有"（过河与桥船），再查态度

3. **摆桌面：把暗账翻成明账**
   - 觉察到"有人有意见但没直说"，立即安排一次正式讨论
   - 开会只谈事不谈人，谈完**当场定下几条**写下来
   - 完成标准：会后有书面结论

4. **先当学生**
   - 布置任务前先问执行的人"你觉得这个怎么干"
   - 完成标准：你上一次改变主意，是因为一线的人给了你信息

5. **安民告示 + 互通情报**
   - 会前：通知议题 + 需准备材料 + 要达成的决定；没准备就不开会
   - 定期主动通报进展（不等对方来问——问就是已经有情绪了）
   - 完成标准：不出现"某条线出了问题两周后才知道"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **只有一件紧急事** → 危机时刻不需要弹钢琴，需要全力以赴
- **一个人干所有事且没有团队** → 先用 `mao-focus-force` 聚焦，别想着统筹
- **具体任务分解** → 这是领导层的注意力分配方法，不是项目管理工具
- **5 人以下小团队** → "互通情报/报告制度"过重，靠日常沟通就够了

### 作者警告的失败模式

- **把"弹钢琴"变成"什么都管"**：名义上统筹，实际变成微观管理（抓紧的是**标准和节点**，不是过程里的每个动作）
- **只抓一件事不管其他**：口头说兼顾，资源全倾斜到一个方向
- **用开会代替管理**：信息同步机制太重，开不完的会反而拖慢效率
- **"摆桌面"让人不适就不摆**：如果背后议论已形成，正面摆出来的代价远小于继续拖

### 作者的盲点 / 时代局限

- **"先当学生"有前提**：你问的人确实在一线、确实知道。问错了人，会得到错误的自信
- **默认为组织场景**：个人使用时，"会议""下级"要翻译成"和自己的定期复盘""向懂的人请教"

### 容易混淆的邻近方法论

- **弹钢琴 ≠ 平均用力**。"凡是有问题的地方都要点一下"是不遗漏，中心工作只能有一个
