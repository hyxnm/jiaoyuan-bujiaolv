# 调查研究法 — 一切结论产生于调查的末尾

## R — 原文 (Reading)

> 「你对于某个问题没有调查，就停止你对于某个问题的发言权。……你对那个问题的现实情况和历史情况既然没有调查，不知底里，对于那个问题的发言便一定是瞎说一顿。」

> 「你对于那个问题不能解决吗？那末，你就去调查那个问题的现状和它的历史吧！你完完全全调查明白了，你对那个问题就有解决的办法了。一切结论产生于调查情况的末尾，而不是在它的先头。」

> 「调查就像『十月怀胎』，解决问题就像『一朝分娩』。调查就是解决问题。」

—— 毛泽东《反对本本主义》

---

## I — 方法论骨架 (Interpretation)

多数事做不成，不是脑子不够，是**手里的材料是假的、少的、二手的**。坐在屋里想出来的办法，输入就是错的，输出必然错。

所以顺序不能反：**先有材料，后有结论**。谁反着来，谁就"瞎说一顿"。

关键的三层：

1. **调查是决策的前置条件，不是准备动作**。"没有调查没有发言权"是一条准入规则——说不出这件事的三个具体数字，你就不具备决策资格。
2. **调查本身就是解决问题**。你以为在收集信息，其实材料齐的那一刻，答案已经浮出来了。所以不要把调查当成本，它是主体过程。
3. **亲手拿到的材料才算数**。搜资料、问别人、刷视频都是二手。要去看真正在做事的人、去跟目标对象面对面、去亲自体验竞品。

配套技术：定调查纲目（大纲+细目）→ 开调查会做讨论式调查（多人互相纠正，不是听单人版本）→ 到会的人要杂（知情人+一线+不同立场，至少三人）→ 亲身出马 → 自己做记录 → 深入一处摸到底（解剖麻雀）。

## A1 — 书中的应用 (Past Application)

### 案例 1：湖南农民运动考察（1927）
- **问题**：党内为"农民运动好得很还是糟得很"吵翻，双方在办公室里辩论，谁也说服不了谁
- **方法论的使用**：不参加辩论，花 32 天实地走访湖南 5 个县，跟各种农民面对面聊，亲自参加农会活动
- **结论**：写《湖南农民运动考察报告》，用一手数据直接终结争论
- **结果**：报告成为农民运动的理论依据，"好得很"成为定论

### 案例 2：《反对本本主义》第七节
- 作者直接给出七条调查技术（调查会、纲目、到会人构成、亲身出马、自己做记录等），是全篇最具体的一份操作清单

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 看别人做某行赚钱了，自己也想做但不知道水深水浅
2. 在几个方向之间纠结，每个看起来都有机会
3. 凭感觉选了个方向，做了三个月才发现根本不对
4. 到处问人"这个能不能做"，每个人说法都不一样
5. 搜了很多资料但还是不敢下决定

### 语言信号

- "我不确定这个赛道行不行"
- "听说是……""大概是……""网上说……"
- "我该问谁？该查什么？"
- "怎么判断这事值不值得做"
- "make sure / validate before I commit"

### 与相邻能力的区分

- 与 `mao-main-contradiction`（抓主要矛盾）的区别：调查解决"材料够不够"，抓主要矛盾解决"从材料里先动哪个"。**顺序上调查在前**——没材料就先别抓主要矛盾。
- 与 `mao-mass-line`（群众路线）的区别：调查多是**一次性**的准入判断；群众路线是**持续循环**的反馈机制。

## E — 可执行步骤 (Execution)

1. **列调查清单**
   - 把"这个方向能不能做"拆成 5-10 个**可通过访谈或搜索回答**的小问题
   - 完成标准：每个问题都能用一句话说清"我去问谁/查什么"
   - 判停条件：若问题拆不出来 → 说明你自己还没想清楚要决策什么，先回到需求厘清

2. **去找真人聊**
   - 3-5 个目标用户深度访谈（30 分钟语音，不是发问卷）
   - 2-3 个同行聊（做相似事情的人，不是竞争对手）
   - 有条件就自己花钱体验 2-3 个竞品
   - 完成标准：每个小问题至少有 **2 个独立信息来源**的答案

3. **把材料加工一遍**（关键，最易跳过）
   - 对材料做四道工序：去粗取精 → 去伪存真 → 由此及彼 → 由表及里
   - 完成标准：能分清"事实"和"我希望如此"

4. **做判断**
   - 整理成一页纸：市场多大、竞争多激烈、我的切入点是什么
   - 完成标准：能对别人说清"我为什么选这个方向"，理由里有**具体数据**

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 你已经在做、数据都有 → 直接用 `mao-main-contradiction` 分析，不要再调查
- 紧急到没时间 → 至少做 2 天缩减版，但不要假装做过
- 纯网上能查到的信息 → 直接搜，不必"实地调研"
- 日常执行类问题 → 判据是"这个决定错了代价大不大"，代价小就不必大兴调查

### 作者警告的失败模式

- **把刷视频当调研**：看了 50 条行业视频不等于调研，你只是在消费内容（V1 反面）
- **先有结论再找证据**：心里已经想做了，"调研"只是找支持自己的信息 —— 调查纲目里必须包含"能推翻我假设的问题"
- **调研了不用**：认真做了但还是凭感觉选，白做

### 作者的盲点 / 时代局限

- 对**调查成本**着墨不多。今天信息过载，无节制调查会变成拖延——所以第 1 步必须定死时间
- 战争年代"亲自出马"成本可承受，今天要区分"必须亲自"和"可委托采集"

### 容易混淆的邻近方法论

- 试点的本质也是一种"在实践中调查"（见路由入口内的"突破一点再推广"），但试点针对**自己的方案**，调查针对**外部事实**
