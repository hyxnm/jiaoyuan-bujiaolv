# 持久战阶段法 — 判断形势，一阶段只做一阶段的事

## R — 原文 (Reading)

> 「第一个阶段，是敌之战略进攻、我之战略防御的时期。第二个阶段，是敌之战略保守、我之准备反攻的时期。第三个阶段，是我之战略反攻、敌之战略退却的时期。」

—— 毛泽东《论持久战》

> 「蒋介石军事力量的优势，只是暂时的现象，只是临时起作用的因素；美国帝国主义的援助，也只是临时起作用的因素；蒋介石战争的反人民的性质，人心的向背，则是经常起作用的因素；而在这方面，人民解放军则占着优势。」

—— 毛泽东《目前形势和我们的任务》

> 「我们看事情必须要看它的实质，而把它的现象只看作入门的向导，一进了门就要抓住它的实质，这才是可靠的科学的分析方法。」

—— 毛泽东《星星之火，可以燎原》

## I — 方法论骨架 (Interpretation)

这一门管两件事：**在低谷中判断形势**（该坚持还是该转向），以及**在长期博弈中定位阶段**（现在该做什么）。

四个核心工具：

1. **看实质，不看现象**。现象只是"入门的向导"。人在低谷最常犯的错，是**把一次挫折推论成整体失败**——把一时的特殊小环境一般化、扩大化。
2. **分开"临时起作用的因素"和"经常起作用的因素"**：
   - 临时因素（会消退）：对方一时的资金、关系、热度；一次风口、一次运气；一次失败、一次丢单
   - 经常因素（决定终局）：你做的事是否符合规律；你有没有真实的能力底座；人心的向背（别人信不信你）
   - **判断要不要坚持，看的是经常因素，不是临时因素。**
3. **长期的事要分三阶段：防御 → 相持（准备反攻）→ 反攻**。
   - 防御期任务：**保存力量**，不打输不起的仗，找到可复制的方法模型
   - 相持期任务：**蓄力**，一点一点蚕食，积小胜为大胜
   - 反攻期任务：**集中资源放大战果**
   - **最危险的是第二阶段**——它不是最惨的，但最熬人：没有明显进展、看不到头，多数人在这里放弃或乱改方向。
4. **判据定音**：问"过去半年，经常起作用的那一栏，是变好了还是变坏了？"——变好→你在相持阶段，方向没错；变坏→这不是低谷问题，是方向问题，要改。

## A1 — 书中的应用 (Past Application)

### 案例 1：论持久战（1938）
- **问题**：抗战最绝望时，两种声音——"亡了亡了"（亡国论）与"三个月打跑日本"（速胜论）
- **方法论的使用**：判断"日本强但小、退步、没朋友；中国弱但大、进步、朋友多"——**时间站在中国这边**。用力量对比的**变动趋势**推三阶段
- **结论**：不打速决战，打持久战，分防御/相持/反攻三阶段
- **结果**：7 年后日本投降，完全符合框架

### 案例 2：星星之火可以燎原（1930）
- **问题**：革命最低潮，党内弥漫悲观情绪
- **方法论的使用**：不是喊口号，而是**逐条分析引起高潮的各种矛盾是否真正向前发展了**——从帝国主义矛盾一路推到赋税、军阀混战、工农破产
- **结论**："中国是全国都布满了干柴"
- **结果**：这是"从矛盾发展看趋势"的范本

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 你的赛道里有几个大号/大公司，感觉怎么做都打不过
2. 做了几个月没起色，开始怀疑是不是该放弃
3. 团队里有人说"赶紧冲"，有人说"算了不做了"，两种极端声音
4. 对手有团队、有资金、有流量，你什么都没有
5. 不确定该坚持还是转行/转向
6. 你刚经历一次成功，担心自己飘（同样重要）

### 语言信号

- "怎么跟大公司/大号竞争"
- "对手比我强太多"
- "长期怎么赢"
- "这条路到底走不走得通"
- "我该坚持还是放弃"
- "是低谷还是方向错了"

### 与相邻能力的区分

- 与 `mao-focus-force`（集中优势兵力）的区别：本卡是**时间维度**（什么时候打、该不该坚持），集中兵力是**空间维度**（在哪一点打）。配套使用：持久战定阶段，集中兵力定突破口。
- 与 `mao-main-contradiction`（抓主要矛盾）的区别：本卡用"矛盾是否向前发展"推趋势，抓主要矛盾是找出哪个矛盾最要紧。**趋势判断用本卡，优先级判断用抓主要矛盾。**

## E — 可执行步骤 (Execution)

1. **先把"实质"和"现象"分开**
   - 画两栏：左边"我看到的（现象）"，右边"它说明的实质是什么"
   - 对每条现象追问三个"所以呢"，直到落到**结构性原因**
   - 完成标准：追问不到结构性原因 = 你看到的还只是现象

2. **列出两类因素，看趋势**
   - 两栏两行：对方/环境的临时因素与经常因素、我的临时因素与经常因素
   - 问：**过去半年，经常起作用的那一栏，是变好了还是变坏了？**
   - 完成标准：能明确回答"变好"或"变坏"
   - 判停条件：**变坏 → 这不是低谷问题，是方向问题，直接跳到第 4 步考虑转向**

3. **给自己的事划阶段，定阶段任务**
   - 我在哪个阶段（防御/相持/反攻）？
   - 这个阶段的任务是什么？（防御期保存力量、相持期蓄力、反攻期放大战果）
   - 什么标志出现，说明可以进下一阶段？**先定好这个标志，免得在相持阶段乱动**
   - 完成标准：能用具体指标说明"我现在是 XX 阶段"

4. **做"坚持/转向"决定**
   - 依据是**经常因素的趋势**，不是投入的沉没成本
   - 方向对、方法错 → 改方法；方向错 → 改方向
   - 完成标准：决定能说清"我改的是方向还是方法"

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **窗口期有限**（某些机会过了就没了）→ 需要速决，不适合持久战
- **你的资源比对手多** → 不需要持久战，直接打
- **赛道本身在萎缩** → 时间不站在任何人那边，持久只是慢性死亡
- **情绪问题已严重影响生活功能**（长期失眠、持续情绪低落）→ 这是需要专业帮助的事，不是方法论能解决的

### 作者警告的失败模式

- **把"持久"理解为"熬"**：持久战不是等，每个阶段都有必须完成的任务
- **在防御期就想搞大动作**：粉丝还没起来就开课、做矩阵，会被打回原形
- **一受挫就想放弃**：只看到"强弱"一个维度就绝望，没看到其他三个维度
- **用"持久战"给拖延找理由**：相持阶段的任务是**蓄力**，有明确积累指标；没有积累的"坚持"是消耗

### 作者的盲点 / 时代局限

- **"看实质"不是自我洗脑**：坚持的前提是经常因素在变好。若它们确实在变坏，"星星之火"就是自我安慰——**承认失败也是一种实质判断**
- **战略藐视、战术重视不能混用**：心态上不被吓倒，但每个具体动作要谨慎。只有前者是盲动，只有后者是怯懦（详见路由入口内的对应能力卡）

### 容易混淆的邻近方法论

- 与"临时因素/经常因素"是同一条方法的两面——前者是判断工具，本卡是应用场景
