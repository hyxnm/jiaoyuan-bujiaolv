# 集中优势兵力 — 至少三倍于敌，打最软的一点

## R — 原文 (Reading)

> 「我军必须集中绝对优势的兵力，即集中六倍、或五倍、或四倍于敌的兵力、至少也要有三倍于敌的兵力，于适当时机，首先包围歼击敌军的一个旅（或团）。这个旅（或团），应当是敌军诸旅中较弱的，或者是较少援助的，或者是其驻地的地形和民情对我最为有利而对敌不利的。」

> 「在战役部署上，必须反对那种轻视敌人、因而平分兵力对付诸路之敌、以致一路也不能歼灭、使自己陷于被动地位的错误的作战方法。」

> 「这种战法的效果是：一能全歼；二能速决。」

—— 毛泽东《集中优势兵力，各个歼灭敌人》

> 「伤其十指，不如断其一指。」

—— 毛泽东《中国革命战争的战略问题》

## I — 方法论骨架 (Interpretation)

全局劣势是常态——你的时间、钱、人、名气永远不够用。**承认这一点，然后靠局部的绝对优势取胜。**

四个要点：

1. **集中，不是"集中一点"，是集中到"三倍以上"**。一倍两倍不算优势，那叫势均力敌，会打成消耗战。**要么不打，要打就要碾压。**
2. **选最软的那一点**。判据三条，占一条即可：**最弱的**（阻力最小）、**最少援助的**（孤立无援）、**条件对我最有利的**（我有独特优势）。占两条以上就打它。
3. **全歼，速决**。这一件事要做到"彻底了结"，不是"推进了 60%"——半吊子成果不产生复利。给它一个明确截止期。
4. **打完一个，再打下一个**。严禁"两个拳头打人"——第一件没结束前，第二件只做维持性动作，不做投入性动作。

反面是什么？**平分兵力**：每个方向都投一点，每个都没打透，全线被动。

## A1 — 书中的应用 (Past Application)

### 案例 1：苏中七战七捷（1946）
- **问题**：粟裕部队在苏中面对国民党大规模进攻，总兵力明显不够
- **方法论的使用**：常规思路是到处布防，但每个方向都守不住。改为**不管其他方向，每次集中全部兵力打敌人一个旅**——19 个团打一个旅，形成 3-6 倍局部优势，先打最弱的，打完一个再打下一个
- **结论**：全局劣势不变，但每一仗都是碾压
- **结果**：七战七捷，歼敌 5.3 万

### 案例 2：四平台自媒体（商业源迁移例）
- **问题**：同时做抖音 2000 粉、小红书 1500 粉、视频号 800 粉、B 站 500 粉，每天四平台发内容，累死但没一个起来
- **方法论的使用**：诊断"总兵力"（时间+精力+内容产能）分散在 4 个战场，每个都不够形成突破
- **结论**：砍掉 3 个平台（真的停，不是少发），选 1 个最有把握的打透
- **结果**：单平台形成资源优势

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 同时做多个平台/项目，每个都一两千、哪个都没起来
2. 又想做短视频、又想做直播、又想做私域，精力被撕成碎片
3. 每个方向都投了一点时间和钱，但哪个都没突破
4. 看别人多平台运营很成功，自己试了发现根本忙不过来
5. 感觉很努力，但不知道自己卡在哪一步

### 语言信号

- "资源不够，该聚焦哪个"
- "什么都做了但没结果"
- "先打哪个平台/客户/方向"
- "我是不是摊得太开了"
- "spread too thin / where should I focus"

### 与相邻能力的区分

- 与 `mao-main-contradiction`（抓主要矛盾）的区别：抓主要矛盾回答"**打哪一个**"（结构判断），本卡回答"**投多少、打赢了怎么转下一个**"（资源判断）。先抓矛盾，再集中兵力。
- 与 `mao-piano`（弹钢琴）的区别：本卡解决"**选一个点打透**"，弹钢琴解决"**其余方向如何维持而不投入**"。两者配套：集中的是中心工作，弹钢琴管"辅以"的第二第三位工作。
- 与 `mao-long-game`（持久战）的区别：持久战是**时间维度**的战略（什么时候打），本卡是**空间维度**的资源配置（在哪一点打）。

## E — 可执行步骤 (Execution)

1. **先承认你的兵力有多少（别自欺）**
   - 列出真实可投入资源：时间（每周小时）、钱、人、注意力（最稀缺），以及"现在被摊在几个方向上"
   - 完成标准：若"被摊在几个方向上" > 3，你已经在平分兵力了

2. **算出你的"三倍"在哪**
   - 不是所有方向都能凑出三倍。**能凑出三倍的那个方向，就是你要打的方向**
   - 完成标准：能说出"我在 X 方向投入 Y，对手大约 Z，形成 Y/Z ≈ 3"
   - 判停条件：若所有方向都凑不出三倍 → 问题不是聚焦而是**兵力总量不足**，先解决"能否抽调"（如退出长期合同、砍固定成本）

3. **选点：三条判据打分**
   - [ ] 最弱的：成功阻力最小
   - [ ] 最少援助的：得不到外部支援，孤立
   - [ ] 条件对我最有利的：我有独特优势（资源/关系/经验/信息）
   - 占一条就够，占两条以上就打它。三条都不占的，排到最后或放弃
   - 完成标准：选定方向能勾上 ≥1 条

4. **定义"打赢"的标准**
   - 给选定方向设明确的数字目标和时间节点
   - 完成标准：有量化指标（不是"试试看"）

5. **打：全歼、速决，然后打下一个**
   - 不达标不换方向——半途而废等于白打
   - 第一件没结束前，第二件只做维持动作
   - 完成标准：中心工作拿到最大块连续时间

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 多个方向相互独立、各自能养活自己 → 不需要集中
- 多个机会同时有截止日期 → 只聚焦一个意味着永久失去其他
- **边际成本接近零的数字业务** → 同一内容多平台分发不算分散兵力
- 资源被长期合同/固定成本锁死 → 先解决"锁定"，否则无兵可调

### 作者警告的失败模式

- **觉得"每个都投一点比较稳"**：这是最危险的策略，看起来稳实际上哪个都不够强
- **打了一半就换方向**：没打到"全歼"就换目标，之前的投入全浪费
- **先挑最难的打**：应该先打最有把握的，积累信心和经验再打难的
- **把集中变成赌博**：集中于一点不等于把所有筹码压上，**留预备队是常识**

### 作者的盲点 / 时代局限

- **"三倍"是原则不是教条**：有些事不需要三倍（低风险试错），有些事三倍也不够（面对绝对实力差距，正确做法是**换战场**而不是加码）
- **集中不等于放弃其余**：其余方向做"维持"不做"投入"。完全放弃会造成塌方

### 容易混淆的邻近方法论

- 与"伤其十指不如断其一指"同源——但后者的重点是**追求全歼而非击溃**，是本卡第 4 条的另一种表述
