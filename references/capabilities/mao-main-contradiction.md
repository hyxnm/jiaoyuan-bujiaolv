# 抓主要矛盾 — 一刀切到问题的命门

## R — 原文 (Reading)

> 「在复杂的事物的发展过程中，有许多的矛盾存在，其中必有一种是主要的矛盾，由于它的存在和发展规定或影响着其他矛盾的存在和发展。」

> 「任何过程如果有多数矛盾存在的话，其中必定有一种是主要的，由于它的存在和发展规定或影响着其它矛盾的存在和发展。捉住了这个主要矛盾，一切问题就迎刃而解了。」

> 「外因是变化的条件，内因是变化的根据，外因通过内因而起作用。」

> 「不同质的矛盾，只有用不同质的方法才能解决。」

—— 毛泽东《矛盾论》

> 「在任何一个地区内，不能同时有许多中心工作，在一定时间内只能有一个中心工作，辅以别的第二位、第三位的工作。」

—— 毛泽东《关于领导方法的若干问题》

## I — 方法论骨架 (Interpretation)

事情难，通常不是问题多，而是**没分出主次，十个指头按十只跳蚤**。

主要矛盾的判据不是"哪个最急"，而是：**哪一个的存在和发展，规定或影响着其它矛盾？** 换句话说——**解决了它，其它的是不是会自己松动？**

四个关键：

1. **材料先加工，再抓矛盾**。列全问题之后，必须走四道工序（去粗取精、去伪存真、由此及彼、由表及里），不能跳过直接抓。四道工序走完，主要矛盾常常自己浮出来。
2. **两个判据**：①"解决了它，别的会不会跟着松动？"②"哪一条拖着不解决，其它都动不了？"
3. **归因落在内因**。外因（环境、对手、时机、运气）你只能适应；内因（你的准备、打法、选择）你能改。**改进清单里内因项必须多于外因项**，全是外因等于宣告自己无能为力。
4. **确认矛盾性质，再选打法**。先问这是**对抗性**（利益根本冲突，要分胜负）还是**非对抗性**（可以商量、可以共赢）。判错是灾难——把同事当敌人打，是把盟友推走。

## A1 — 书中的应用 (Past Application)

### 案例 1：1937 年红军的复杂局面
- **问题**：军事被围剿、经济被封锁、政治被孤立、内部路线争论，四个问题同时压来
- **方法论的使用**：如果每个问题平均使力必死；用矛盾分析找出主要矛盾，解决它其余跟着松动
- **结论**：找到主要矛盾，集中力量打
- **结果**：形成《矛盾论》的系统判断框架

### 案例 2：自媒体博主的诊断（商业源迁移例）
- **问题**：粉丝 3000 增长慢、课程卖不动、不知做抖音还是小红书、剪辑外包差、什么都做但没做好
- **方法论的使用**：拆链——粉丝少（流量）→课卖不动（变现）→平台选择（渠道）→剪辑（执行）。问哪个是主要矛盾
- **结论**：主要矛盾**不是流量**——3000 粉卖不动，3 万粉大概率也卖不动，因为课程没打中痛点。主要矛盾是**产品和需求不匹配**
- **结果**：先解决产品，其余连锁松动

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 同时在焦虑流量、内容、变现、团队……不知先解决哪个
2. 做了很多事但没起色，怀疑方向错了
3. 别人给了一堆建议，每条都有道理但互相矛盾
4. 每天很忙但月底一算没赚到钱
5. 觉得"只要 XXX 就好了"，但解决了之后发现还是不行

### 语言信号

- "好几件事搅在一起，不知道先干哪个"
- "我到底该先解决什么"
- "感觉很努力但没结果，问题出在哪"
- "先做哪件？" / "prioritize / what's the bottleneck"
- "为什么我做了这么多还是没起色"

### 与相邻能力的区分

- 与 `mao-research`（调查研究）的区别：调研解决"材料够不够"，本卡解决"从材料里先动哪个"。**没说清事实前不要抓矛盾**——那是"瞎说一顿"的高级版。
- 与 `mao-focus-force`（集中优势兵力）的区别：本卡回答"打哪一个"，集中兵力回答"投多少资源、打赢了怎么转下一个"。**先抓矛盾，再集中兵力。**
- 与 `mao-piano`（弹钢琴）的区别：本卡是**一次性诊断**，弹钢琴是**长期统筹**。

## E — 可执行步骤 (Execution)

1. **列全（5 分钟）**
   - 把当前所有让你难受的事**全部**写下来，不排序、不筛选
   - 完成标准：写满 7 条以上（写不满说明没想全）

2. **四道工序加工**（最易跳过，必须走）
   - 去粗取精（划掉无关与次要）→ 去伪存真（核对来源、剔除"我希望是这样的"）→ 由此及彼（把孤立的事连成因果链）→ 由表及里（穿透表象：真正的矛盾是"钱不够"还是"信任没了"？）
   - 完成标准：能画出问题之间的关系链
   - 判停条件：若材料明显不真不全 → **回到 `mao-research` 补调查，别硬抓**

3. **判主要矛盾（一问定音）**
   - 对清单每条问："解决了它，别的会不会跟着松动？"
   - 判不出来就用第二判据："哪一条拖着不解决，其它都动不了？"
   - 完成标准：能用一句话说清"我最该解决的是 ______"

4. **归因落在内因**
   - 把结果拆成外因/内因两栏，改进清单里内因项必须多于外因项
   - 完成标准：内因项 ≥ 外因项

5. **确认矛盾性质，选对打法**
   - 对抗性 → 斗争，讲策略分寸（配合路由入口内的"有理有利有节"）
   - 非对抗性 → 讨论、说服、调整，**不能用"歼灭"思路**
   - 完成标准：说清了"这是对抗性还是非对抗性"，并据此选了打法

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题已经很明确（"我就是不会剪辑"）→ 直接去学，不需要分析
- 需要的是信息而不是分析 → 先做 `mao-research`
- 刚开始还没有足够多的问题 → 先干起来再说

### 作者警告的失败模式

- **把"症状"当"病因"**：流量少是症状，内容不行才是病因。别在症状上使劲
- **把"紧急的"当"重要的"**：剪辑质量差很紧急，但不是让你不赚钱的原因。判据是"规定或影响其它矛盾"，不是"催得最凶"
- **回避真正的主要矛盾**：因为主要矛盾往往最难解决、最不想面对（如"我的课确实没价值"）

### 作者的盲点 / 时代局限

- **主要矛盾会变**：解决了旧的新的会顶上来。每隔一段时间要重新判，别拿上个月的结论用到底
- **内因论不等于自责论**：承认内因是为了拿回主动权，不是把外部的不公合理化。遇真正的外部不公，该斗争还是斗争

### 容易混淆的邻近方法论

- "主要矛盾"≠"矛盾的主要方面"。前者是"哪一对矛盾"，后者是"这一对里哪一边占支配地位"
