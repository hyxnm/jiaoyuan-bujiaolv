# 合并术语词典（四源去重 · 候选池）

## A. 认识与判断

| 术语 | 作者含义（≠ 常识用法） |
|---|---|
| **实事求是** | 从客观事物出发、研究出内在规律；≠ 日常的诚实/务实 |
| **调查研究** | 有纲目、亲身参与的系统信息收集；≠ 走马观花/网上搜搜 |
| **教条主义 / 本本主义** | 用现成方案替代独立调查的思维惰性；≠ 按规矩办事 |
| **经验主义** | 把一时一地的成功当普遍规律外推 |
| **去粗取精、去伪存真、由此及彼、由表及里** | 材料加工的四道工序（原文） |
| **感性认识 / 理性认识** | 原料 vs 成品；不加工的原料是狗肉账 |
| **解剖麻雀**（后人概括） | 与其十个问题摸皮毛，不如一个问题摸到底 |
| **胸中有数** | 把模糊判断变成数量门槛（原文） |

## B. 矛盾与分层

| 术语 | 作者含义（≠ 常识用法） |
|---|---|
| **矛盾** | 事物内部对立统一关系；≠ 冲突，包含和平共存的差异 |
| **主要矛盾** | 规定或影响其他矛盾的那一个；≠ 最紧急的问题（原文） |
| **矛盾的主要方面** | 一对矛盾里占支配地位、决定性质的那一方 |
| **矛盾的普遍性 / 特殊性** | 矛盾无处不在，但每个长得不一样；套公式必错 |
| **对抗性 / 非对抗性矛盾** | 利益根本冲突 vs 可以共赢；判错=灾难 |
| **内因 / 外因** | 外因是条件，内因是根据（原文） |
| **具体问题具体分析** | 不拿一般原则当现成公式硬套 |
| **两点论与重点论** | 分析要全面，下手要有重点 |
| **主要矛盾 / 次要矛盾** | 哪一对 vs 哪一边（与"主要方面"区分） |

## C. 战略与力量

| 术语 | 作者含义（≠ 常识用法） |
|---|---|
| **集中优势兵力** | 局部形成 3:1-6:1 压倒优势，追求全歼；≠ 笼统聚焦（原文） |
| **伤其十指不如断其一指** | 拒绝"击溃战"，要"歼灭战"（原文） |
| **持久战** | 积极、有阶段目标的以弱胜强战略；≠ 被动拖延（原文） |
| **阶段性 / 过程阶段论** | 防御→相持→反攻，一阶段只做一阶段的事（原文） |
| **临时起作用的因素 / 经常起作用的因素** | 判断"坚持还是转向"只看后者（原文） |
| **战略上藐视，战术上重视** | 敢想+细打，两端缺一不可 |
| **全局与局部** | 局部隶属全局，输掉"对全局有决定意义的一着"才致命 |
| **积极防御** | 防御中的进攻，持久中的速决，内线中的外线（原文） |
| **纸老虎** | 战略判断：表面强大的对手有致命弱点；≠ 对手不可怕 |
| **独立自主** | 基点放在自己力量上，关键路径不押外部资源 |
| **流寇主义** | 只流动不扎根，没有稳定根据地（能力底座/客户基本盘） |

## D. 领导与执行

| 术语 | 作者含义（≠ 常识用法） |
|---|---|
| **群众路线** | 收集→系统化→验证→反馈的完整决策闭环；≠ 亲民/接地气（原文） |
| **一般号召与个别指导相结合** | 光喊口号没用，要挑点做透再推广（原文） |
| **骨干与三部分人** | 积极分子当骨干带动中间、争取落后（原文） |
| **一个中心工作** | 一定时间内只能有一个中心，其余"辅以"（原文） |
| **弹钢琴** | 有主旋律同时兼顾其他、有节奏配合；≠ 平均用力（原文） |
| **抓紧** | "在做"和"做成"是两回事（原文） |
| **安民告示** | 会前通知议题材料，没准备不开会（原文） |
| **互通情报** | 不交流就"缺乏共同的语言"（原文） |
| **过河与桥船** | 布置任务必须同时给方法/资源（原文） |
| **分工负责** | 唯一责任人 + 明确截止时间；禁止"大家一起负责" |
| **有理、有利、有节** | 不主动挑事但被打了必还手；没把握不打；得手就收（原文） |

## E. 纠偏与自省

| 术语 | 作者含义（≠ 常识用法） |
|---|---|
| **实践—认识—再实践** | 每轮必产出认识升级，否则是原地打转（原文） |
| **放下包袱，开动机器** | 先卸情绪负担，再用脑筋（原文） |
| **惩前毖后，治病救人** | 纠错对事不对人，落点是改进非追责（原文） |
| **批评与自我批评** | 组织层面的系统纠偏；≠ 个人道德反省 |
| **力戒骄傲** | 没犯大错且有成绩的人也不要骄傲（原文） |
| **形式主义（党八股）** | 按外部标志分类而非内部联系（原文） |
| **统一战线** | 有目标、保持独立性、有退出条件的阶段性联盟；≠ 泛泛合作 |
| **民主集中制** | 先充分讨论（民主）后统一执行（集中）；≠ 投票或拍板 |
