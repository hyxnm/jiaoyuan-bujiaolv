# 教员不焦虑

> 从《毛泽东选集》提炼的 **21 张思维方法卡**，帮你解决现实中的纠结与内耗。

不是书摘，也不是鸡汤。每张卡针对一类具体困境，给出**可执行步骤**和**判停条件**——什么时候该停、什么时候该转向，都写清楚。

## 解决什么问题

| 你的困境 | 用哪张卡 |
|---|---|
| 不确定某个方向值不值得进 | 调查研究法 |
| 一堆问题不知先解决哪个 | 抓主要矛盾 |
| 资源不够，该聚焦到哪 | 集中优势兵力 |
| 打不过强手，该坚持还是放弃 | 持久战阶段法 |
| 产品卖不动，不知问题在哪 | 群众路线闭环 |
| 多头任务忙不过来、天天救火 | 弹钢琴与抓紧 |
| 写的东西又长又空、没人看 | 反对党八股 |
| 说不清值不值得、够不够 | 胸中有数 |
| 说不清好还是坏、行还是不行 | 划清界限 |
| 该不该撕破脸、该斗争还是协商 | 矛盾性质判断 |
| 团队出了问题说不清、批评不伤人 | 惩前毖后治病救人 |
| 复盘了还是犯同样错 | 实践—认识螺旋 |
| 学来的方法不管用、能否照搬 | 反对本本主义 |

完整 21 张卡的路由表见 [`SKILL.md`](SKILL.md)。

## 使用方式

这是一个 Agent Skill 包。将整个目录放入技能的加载路径（如 `~/.workbuddy/skills/`）后，按 [`SKILL.md`](SKILL.md) 的路由表，针对具体意图加载对应的 1 张能力卡即可。

也可通过 SkillHub 安装：

```bash
skillhub install jiaoyuan-bujiaolv --namespace user_806b1075
```

## 适用边界

**不适用**：

- 纯信息查询、常识问答
- 专业法律 / 医疗 / 财务 / 投资意见
- 政治立场评价、历史事件是非判断
- 角色扮演历史人物本人
